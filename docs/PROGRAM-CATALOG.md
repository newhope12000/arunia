# 프로그램 목록과 언론 보도 화면 정리 · 2026-10-02

## 요청과 판단

운영 사이트에서 그만둘만두 공모전이 열린 것으로 표시되는 오류를 수정하고, 커리어 4기를 프로그램에 포함해 항목이 늘어나도 쉽게 확인할 수 있도록 정리한다. 뉴스는 홍보 카드보다 원문 기사와 출처가 명확한 정보 목록으로 보이도록 한다.

사용자 동기는 현재 참여할 수 있는지 빠르게 확인하고 종류·기간·내용을 비교하는 것이다. 마감한 공모전의 응모 링크, 내부 사업 기획 문구와 긴 홍보 박스는 이 흐름을 방해한다. MBTI별 실제 이용 데이터를 확보하지 않았으므로 유형별 행동을 사실로 단정하지 않는다. 빠른 목록 비교와 자세한 안내 읽기를 모두 지원하는 구조를 선택했다.

## 데이터 근거와 범위

- 그만둘만두: 기존 `/programs.html#contest`에 접수 2026년 9월 1~22일, 기존 공지에 최종 발표 10월 7일(수). 접수 마감 표시와 결과 안내는 유지하며 외부 응모 버튼을 제거한다.
- CORE-UP 4기: 공식 `/career-core-up`에 접수 9월 7~30일, 최종 30명, 10월 12일 개별 통지 예정. 공개 목록에서 마감 상태를 명시하고 기존 상세로 연결한다. 참가 연령은 원본 화면끼리 표현 차이가 있어 목록에서 새 기준을 만들지 않는다.
- 훈민정음: 10월 6일(화) 18시 마감, 20~27세, 수석·차석·장려상 혜택과 기존 신청 흐름을 보존한다.
- 뉴스: 앞서 확인한 대학저널·공감신문 원문 제목, 매체·기자·발행일·도메인을 표시한다. 본문은 기사 소개임을 명시하고 외부 원문 링크를 별도로 제공한다. 원문 사진·로고·기사 본문을 복제하지 않는다.

## 구현과 확장

`renewal/program-data.mjs`의 `PROGRAM_CATALOG`에 프로그램 정보를 추가하면 해당 종류의 목록이 함께 생성된다. 종류는 커리어 / 콘텐츠·모임·클래스 / 공모전·이벤트로 나누고 지난 기수는 간단한 링크 목록으로 유지한다. 동일한 카드에 종류, 접수 상태, 제목, 소개, 기간·내용, 안내 링크를 같은 위치에 둔다. 날짜가 있는 접수 상태는 방문 시 갱신해 이전에 생성한 정적 화면도 마감 후 열린 것으로 남지 않도록 한다.

`scripts/build-official-programs.mjs`는 원본 복사 뒤 공식 `/programs.html`만 새 공통 디자인으로 생성한다. 기존 `#contest`는 접힌 상세 안내로 남기며 원래 주소로 들어오면 펼쳐진다. 포스터·과거 공모 조건·시상 내역도 보존한다. 상세·신청·API·시트·Telegram 및 `/v0_1/`은 현재 경로와 기능을 유지한다.

뉴스는 전체 폭 기사 행으로 정리하고 자체 상세 링크와 외부 원문 링크를 구분한다. 미래 기사 데이터 추가 시 목록과 상세 생성 방식은 그대로다.

추가 요청에 따라 전체 웹페이지의 글꼴은 공식 Pretendard 변수폰트를 자체 자산으로 제공하고 공통 스타일로 적용한다. 기존 상세·신청·완료 화면과 리뉴얼 시안·미리보기 모두 같은 글꼴을 실제로 로드한다. 뒤이어 요청한 행사 콘셉트에 맞춰 훈민정음 제목·소제목에는 마루부리를 사용하고 본문·버튼·입력란에는 Pretendard를 유지한다. 네이버 공식 사용 안내에서 상업 이용 및 라이선스 동봉 배포 조건을 확인하며 파일과 라이선스를 함께 보존한다. 이미지·포스터의 픽셀 및 문구는 변경하지 않는다.

## 검증

마감 상태·마감 시각 경계, 이전 화면의 상태 갱신, `#contest` 도착 시 펼침, 추가 프로그램 생성, 원문 정보·링크·특수 문자, 실제 정적 출력의 내비게이션과 기존 상세·응모 파일 보존을 확인한다. 실제 응모 전송 없이 데스크톱·모바일과 공식 배포 결과를 검토한다.

배포 전 전체 테스트 51개 통과, `build:review` 정상 완료. 로컬 브라우저에서 운영·완료·뉴스·시안·미리보기 37개 화면의 공통 폰트 연결과 로딩을 확인했다. 프로그램·공모전 펼침·뉴스 목록·상세·훈민정음 안내/응모/접수확인·CORE-UP 안내/완료의 모바일 390px 화면에서 가로 넘침이 없고 신청 입력란은 Pretendard를 유지한다. 그만둘만두 상세에 열린 상태나 응모 버튼이 없고 포스터와 발표 안내는 보존된다. 폼 전송·시트 변경·Telegram 알림 시험은 발생시키지 않았다.

소개·가치·비전·성장 3기·이전 4기 화면에서 발견한 기존 인라인 다열/고정폭 그리드는 모바일에만 1열 또는 작은 카드 2열로 전환했다. 390px·320px 화면에서 다섯 페이지의 콘텐츠와 문서 가로 넘침이 없고, 1280px 화면의 기존 통계 4열 배치는 유지된다. 이 수정 후 전체 테스트 51개와 최종 빌드도 다시 통과했다.
