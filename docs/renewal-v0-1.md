# 어른이아 V0.1 리뉴얼 시안

2026년 9월 23일 기획안과 추가 수정 요청을 반영한 청년 성장 플랫폼 시안입니다. 기존 홈페이지와 메뉴의 성격을 유지하면서 초록색 CI(`#217346`), 자연스러운 해요체, CORE-UP 4기 모집 정보, 한국 청년의 활동을 표현한 새 이미지로 정리했습니다.

## 공개 경로와 범위

- 기존 홈페이지는 `/`, 상담 서비스 개편안은 `/preview/`에서 그대로 제공합니다.
- 이번 리뉴얼 시안과 연결된 내부 페이지·이미지는 모두 `/v0_1/` 아래에 있습니다.
- `/v0_1/`은 14개의 정적 HTML 페이지로 구성하며 회원·결제·상담 접수 API를 사용하지 않습니다. 4기 지원 버튼만 승인된 외부 지원 주소로 이동합니다.
- 시안에는 `noindex, nofollow` 메타 태그와 응답 헤더를 적용하고 루트 `robots.txt`에서도 `/v0_1`을 제외합니다. 검색 제외는 접근 제한 기능이 아니며 링크를 아는 사람은 볼 수 있습니다.

| 페이지               | 주소                     |
| -------------------- | ------------------------ |

## 빌드와 수정 위치

Node.js 22.12 이상에서 저장소 루트를 기준으로 실행합니다.

```sh
npm ci
npm run build:review
```

`scripts/build-review.mjs`가 기존 사이트를 `review-dist/`, 상담 시안을 `review-dist/preview/`에 생성한 뒤 `scripts/build-renewal.mjs`의 `buildRenewal()`을 호출해 `review-dist/v0_1/`을 만듭니다. Vercel에는 세 경로를 포함한 `review-dist/`를 배포합니다. `npm run dev`는 기존 상담 앱의 개발 명령이며 이번 정적 리뉴얼 시안을 제공하는 명령은 아닙니다.

| 파일                         | 수정할 내용                                      |
| ---------------------------- | ------------------------------------------------ |
| `renewal/feature-pages.mjs`  | 메인과 CORE-UP 4기 상세                          |
| `renewal/content-pages.mjs`  | 카테고리, 지난 프로그램, 정책 안내               |
| `renewal/layout.mjs`         | 공통 메뉴·푸터·페이지 메타 정보                  |
| `renewal/shared.mjs`         | 모집 정보, 지원 주소, 공통 링크·이미지·과정      |
| `renewal/style.css`          | 초록색 CI, 레이아웃, 반응형 스타일               |
| `renewal/site.js`            | 모바일 메뉴와 모집 상태 표시                     |
| `renewal/availability.mjs`   | 모집 시작·마감 시각 판정                         |
| `renewal/assets/images/`     | 메인·멘토링·워크숍 이미지의 640/1600px WebP 파일 |
| `renewal/image-prompts.json` | AI 이미지 제작 프롬프트와 파일 목록              |
| `scripts/build-renewal.mjs`  | `/v0_1/` 정적 페이지·자산 생성                   |

## 기본 서비스와 추가 모집

사용자 정정에 따라 기본 구성은 기존 홈페이지의 라이프 디자인·커리어 탐색 플랫폼입니다. 홈은 브랜드 소개 → 고민 공감 → 기본 프로그램 3종 → 구독 플랜 → 모집·이벤트 → 경험 이야기 → 일반 시작 안내 순서입니다. CORE-UP 4기는 기본 서비스 전체를 대체하지 않는 별도 기수 모집입니다.

- 기본 프로그램: 전문가 콘텐츠 아카이브, 프리미엄 라운드테이블, DAY ONE 클래스
- 구독: 무료, 베이직 월 9,900원/연 99,000원, 프리미엄 월 29,000원/연 290,000원
- 가격과 혜택은 저장소의 `legacy/pricing.html`, `legacy/programs.html`을 기준으로 복원했습니다.
- 주요 메뉴·공통 CTA·푸터는 프로그램 탐색과 구독 비교로 연결하고, 모집·이벤트에서 CORE-UP 4기와 지난 모집을 확인합니다.
- 만 26세 이하 및 서울 관련 자격은 CORE-UP 4기에만 적용합니다. 일반 프로그램 전체의 이용 자격으로 확장하지 않습니다.

## 모집 정보와 마감 처리

- 프로그램명: 커리어 CORE-UP 성장 프로젝트 4기
- 지원 기간: 2026년 9월 7일~9월 30일
- 대상: 만 26세 이하 청년 중 서울시 거주자 또는 서울 소재 대학·직장 소속인 사람
- 모집 인원: 최종 30명
- 결과 안내: 2026년 10월 12일 개별 안내
- 외부 지원 주소: <https://arunia-career-core-up.lkhy48.chatgpt.site/#apply>

지원 페이지는 새 창에서 열립니다. 현재 외부 페이지에서 ChatGPT 로그인을 요구하는 상황을 확인했으며, 화면에서도 로그인이 필요할 수 있다고 안내합니다. 신청 완료 여부는 외부 지원 페이지에서 확인해야 합니다. 이 시안은 지원 내용을 저장하거나 완료 화면을 대신 표시하지 않습니다.

모집 시각은 한국 시간으로 고정합니다. `2026-09-07T00:00:00+09:00` 이전에는 ‘모집 예정’, 해당 시각부터 `2026-10-01T00:00:00+09:00` 직전까지는 ‘모집 중’, 그 이후에는 ‘모집 마감’으로 표시합니다. 페이지를 열 때 브라우저 현재 시각으로 판정하며, 마감 후 외부 지원 버튼은 `/v0_1/programs.html`의 기본 프로그램 안내로 바뀝니다. 외부 지원 페이지의 실제 접수 마감은 해당 운영자가 별도로 관리해야 합니다.

## 콘텐츠 고지와 남은 운영 정보

- 사진 3장은 한국 청년의 활동 장면을 AI로 만든 연출 예시입니다. 실제 참여자·멘토·운영 현장 사진이 아닙니다. 이미지 대체 텍스트, 일부 사진 캡션, 공통 푸터에서 구분합니다.
- 메인의 이야기 3개는 화면 구성용 가상 사례이며 실제 후기나 활동 성과가 아닙니다. 이야기 영역에 가상 예시임을 표시했습니다.
- 문의 이메일·연락 채널은 미정입니다. 구독 페이지는 기존 홈페이지의 무료·베이직·프리미엄 구성과 가격·혜택을 안내하며 실제 가입·결제·수신 기능은 아직 연결하지 않습니다.
- CORE-UP 4기의 참가비, 전체 진행 일정, 장소, 참여 시간은 확정 안내 전입니다. 구체적인 운영 정보를 받은 뒤 지원 판단에 필요한 내용으로 보충해야 합니다.
- 개인정보·이용 안내는 검토 페이지의 범위를 설명하는 문서입니다. 실제 운영 정보와 연락처를 확정한 정식 정책을 대신하지 않습니다.

수정 후 `npm test`와 `npm run build:review`로 링크·모집 상태·기존 경로 보존 여부를 확인하고, 공개 주소에서도 메인과 하위 페이지를 확인합니다.

## 공식 로고

`renewal/assets/brand/arunia-wordmark.jpg`는 사용자가 제공한 로고 원본입니다. 모든 14개 페이지의 헤더·푸터에서 공유하며, 기존 0200 심볼과 중복 텍스트는 제거했습니다. 검정 글자와 파란 점은 변경하지 않고 CSS `mix-blend-mode: multiply`로 흰색 영역을 각 구간 배경에 맞춥니다. 파비콘은 원본을 포함한 SVG의 viewBox로 마지막 원형 글자와 파란 점을 표시합니다. 원본 JPEG 픽셀은 수정하지 않았습니다.
