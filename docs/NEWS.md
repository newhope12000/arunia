# 공식 메인 문구 정리와 뉴스 · 2026-10-02

## 요청과 설계

사용자는 운영 사이트의 사진 위·아래 문구와 버튼 아래 보조 문구를 제거하고, 메인 하단의 기사 목록과 개별 상세 페이지를 요청했다. 현재 기사는 두 개이며 이후에도 추가할 수 있게 한다.

방문자가 실제 서비스 안내와 제작 중인 시안을 혼동하지 않도록 공식 메인의 가상 후기 영역을 제외하고, 주요 소개·프로그램·구독·이벤트 설명은 유지한다. 사진 설명과 버튼 아래 안내 문구를 덜어내며 이미지 원본 픽셀과 대체 텍스트는 유지한다. MBTI 유형을 실제 검증된 이용 행동으로 가정하지 않고, 뉴스 목록을 빠르게 훑는 흐름과 개별 보도를 자세히 읽는 흐름을 모두 지원한다.

공식 메인은 뉴스 두 건을 보여주고 전체 목록은 `/news`에서 제공한다. 현재는 원문 제목·매체·기자·발행일·출처 도메인을 기사 행에 표시하며 상세 소개와 외부 원문 링크를 구분한다. 상세에서는 원문 제목, 어른이아가 작성한 짧은 기사 소개와 원문 링크를 제공한다. 원문 전체나 언론사 이미지를 복제하지 않는다. 과거 기사에 있는 모집·발표 날짜는 현재 행사 일정으로 재사용하지 않는다.

## 추가 방법과 파일

`renewal/news-data.mjs`의 `NEWS` 배열에 항목을 추가한다. `slug`, 자체 소개 제목 `title`, 원문 제목 `sourceTitle`, `publisher`, `author`, 발행일 `published`(YYYY-MM-DD), HTTPS `sourceUrl`, 카드 소개 `excerpt`, 자체 요약 문단 `paragraphs`를 기록한다. 슬러그는 소문자 영문·숫자·하이픈으로 정하고 기존 항목과 중복하지 않는다.

빌드하면 최신순 메인 카드, 전체 목록과 `/news/<slug>` 상세가 자동 생성된다. 새로운 개별 경로마다 Vercel 설정을 추가할 필요가 없다. 데이터 검증은 잘못된 날짜·중복 슬러그·안전하지 않은 원문 주소로 사이트를 게시하는 것을 막는다.

- `renewal/news-pages.mjs`: 카드·목록·상세 화면
- `renewal/official-shared.mjs`: 공식 사이트의 공통 링크·자산 경로
- `scripts/build-news.mjs`: 뉴스 정적 페이지 생성
- `vercel.json`: 확장자 없는 뉴스 경로와 이전 형식 주소 정리

공식 메인에서 기사 등록 안내 같은 개발 문구는 표시하지 않는다. 기존 훈민정음·CORE-UP·그만둘만두·지난 프로그램, 행사 API·시트·Telegram 연결은 보존한다. 첨부 이미지의 CORE-UP 화면은 `/v0_1/growth_4.html`의 공통 소스이므로 해당 사진 캡션과 ChatGPT 로그인 안내도 제거하고 지원 주소를 현재 공식 CORE-UP 화면으로 맞춘다. 모집 날짜와 참가 조건은 이번 문구 정리에서 변경하지 않는다.

## 검증 범위

실제 정적 빌드의 메인→뉴스 목록·상세→원문·목록 복귀 경로를 확인한다. 추가 기사 자동 생성, 중복·잘못된 데이터, 특수 문자 출력과 기존 행사·시안 경로 보존도 검증한다. 데스크톱·모바일 화면을 확인한 뒤 공식 GitHub main에 반영하고 기존 Vercel 자동 배포의 결과를 확인한다.

배포 전 검증: 전체 테스트 44개 통과, `build:review` 정상 완료, 공백 오류 없음. 로컬 브라우저에서 메인 사진·버튼 주변 문구 제거, 두 뉴스 카드→개별 상세→목록 복귀, 원문 출처와 링크를 확인했다. 모바일 390px에서 목록·상세의 가로 넘침이 없고, 첨부 CORE-UP 화면의 사진 캡션과 로그인 안내도 제거된 것을 확인했다. 실제 응모 제출이나 Telegram 시험 알림은 이번 화면 수정에서 발생시키지 않았다.
