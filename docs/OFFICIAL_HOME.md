# 공식 메인 페이지 교체 · 2026-10-02

## 요청과 코드 확인

사용자 요청은 `https://arunia.vercel.app/v0_1/`의 내용과 이미지로 공식 메인 `https://www.arunia.co.kr/`을 교체하는 것이다. 추가 요청에 따라 훈민정음, 커리어 CORE-UP 4기와 기존 이벤트 진입점을 누락하지 않는다.

GitHub `newhope12000/arunia`의 최신 main `e782838`에서 작업을 시작했다. 저장소의 `renewal/feature-pages.mjs`가 `/v0_1/` 메인 콘텐츠를 만들고, `renewal/layout.mjs`가 공통 화면, `renewal/assets/`가 사용자 로고와 기존 리뉴얼 이미지를 제공한다. 실제 공개 `/v0_1/`에서도 동일한 메인 구성과 이미지를 확인했다.

## 참여 흐름과 범위 확정

설명을 먼저 읽는 방문자는 브랜드 소개·고민 공감·프로그램·구독 구성을 순서대로 볼 수 있고, 행사를 찾는 방문자는 메뉴와 모집·이벤트 영역에서 바로 상세 페이지로 이동할 수 있게 한다. MBTI 유형별 행동은 검증된 사실로 가정하지 않는다. 빠른 참여와 정보 탐색을 모두 지원하는 구조를 실제 링크·모바일 화면으로 확인한다.

코드 대조 결과 `/v0_1/`에는 훈민정음과 그만둘만두가 없고 CORE-UP 지원 주소도 이전 외부 주소를 사용한다. 따라서 메인 콘텐츠와 이미지는 재사용하되 이벤트 목록은 공식 운영 페이지를 기준으로 보완한다. 기존 하위 페이지의 문의·정책·구독·행사 폼을 시안으로 교체하지 않는다.

- 훈민정음 안내 `/hunmin`, 응모 `/hunmin/apply`: 20~27세, 10월 6일 18시 마감, 수석·차석·장려상의 최신 혜택을 유지한다.
- CORE-UP 4기 `/career-core-up`: 공식 안내의 프로그램 설명과 연결을 사용한다. 시안의 별도 지원 주소나 과거 모집 시점 판정이 공식 진입 버튼을 바꾸지 않도록 한다.
- 그만둘만두 `/programs.html#contest`: 기존 최종 수상자 발표 일정 변경 공지와 10월 7일 발표 안내를 메인에서 계속 제공한다.
- 성장 프로젝트 1·2·3기와 리더십 프로그램의 기존 상세 주소를 유지한다.

공식 메인의 시안 리본·V0.1 제목·검색 제외 표기는 제거하고 canonical과 공유 주소를 `https://www.arunia.co.kr/`로 설정한다. AI 이미지와 가상 이야기의 예시 표시는 유지한다. `/v0_1/`와 `/preview/`는 기존 검토 화면과 검색 제외 설정을 유지한다.

## 구현 위치

`renewal/official-home.mjs`가 공용 리뉴얼 콘텐츠로 공식 메인을 렌더링한다. `scripts/build-official-home.mjs`는 메인과 `/assets/renewal/` 자산을 생성한다. 기존 이미지의 픽셀이나 로고 원본은 변경하지 않는다. `scripts/build-review.mjs`는 기존 하위 페이지와 이벤트를 복사하고 두 시안을 만든 후 공식 메인을 루트에 게시한다.

기존 `legacy/index.html`은 Git의 이전 원본으로 보존한다. 배포된 루트와 `/index.html`은 새 공식 메인이다. 나머지 기존 주소, API, Google Sheets 탭, 접수번호와 Telegram 연결은 이 작업에서 수정하지 않는다.

## 검증

빌드 출력의 메인·메뉴 링크·앵커·자산을 검증하고, 행사와 기존 하위 페이지 및 두 시안의 보존을 확인한다. 배포 후 공식 도메인의 메인, 모바일 메뉴, 이벤트 진입과 접수 준비 상태를 읽기 전용으로 확인한다. 실제 응모나 추가 알림 발송은 필요하지 않다.

- `npm test` 40개 통과, `npm run build:review` 성공, `git diff --check` 통과.
- 실제 정적 빌드 테스트에서 메인 링크·앵커·자산과 행사·지난 프로그램 경로를 확인했고, 메인 이외 기존 HTML과 공개·시안 이미지가 원본과 바이트 단위로 같음을 검증했다.
- `/v0_1/` 14개 HTML의 수정 전후 SHA-256이 모두 동일하다.
- 배포 전 데스크톱 두 열 메인과 390px 모바일 화면을 확인했다. 메뉴의 모집·이벤트 링크가 이벤트 영역으로 이동하며 모바일 메뉴가 닫힌다. 화면 너비와 문서 너비가 같아 가로 넘침이 없고 메인·워크숍 이미지가 정상 로드된다.

## 공식 문의 이메일 전달 추가 · 2026-10-08

사용자는 공식 `/contact.html`의 기존 문의 처리 과정을 유지하면서 동일 문의를 `hwajeongup@gmail.com`에도 전달하도록 요청했다. 기존 `/v0_1/contact.html`은 이미 해당 Gmail과 FormSubmit에 연결되어 있었으나, 공식 문의 페이지는 별도 Google Apps Script를 사용하고 있었다. 외부 Apps Script 내부의 기존 최종 수신 이메일은 저장소나 공개 코드에서 확인할 수 없었다. 이를 Gmail이었다고 추정하지 않는다.

기존 양식의 이름·이메일·관심 프로그램·선택 메시지와 Google Apps Script 주소·POST·네 필드 본문을 유지한다. 유효한 입력과 이메일 전달 동의 후 한 번 제출하면 기존 경로에 한 번 전송하고, FormSubmit을 통해 같은 내용을 `hwajeongup@gmail.com`에도 한 번 전달한다. `legacy/assets/contact-inquiry.js`가 해당 페이지의 문의 처리를 담당하고, 공통 `legacy/script.js`의 중복 제출 처리는 제거했다. 외부 Apps Script 원본·Google Sheets·기존 후속 처리에는 변경하지 않는다.

참여 동기는 편한 문의와 답변 확인이며, 이탈 우려는 수신 여부의 불확실성과 재제출로 인한 중복이다. 기존 입력 화면을 유지하고 직접 이메일 링크를 제공하며, 응답이 불확실할 때 내용을 남기고 자동 재전송을 하지 않는 방식으로 대응한다. MBTI별 효과나 전환율은 조사 없이 단정하지 않는다.

- 기존 요청은 `no-cors` 응답이어서 저장 완료를 증명할 수 없다. 기존 경로의 완료 여부와 이메일 전달 서비스의 접수 응답을 구분해 안내한다.
- 이메일 응답의 HTTP 성공과 `success:true` 또는 `"true"`를 함께 확인한 뒤 이메일 전송 요청의 접수 안내를 표시한다. 이는 Gmail 편지함의 실제 수신 확인과 구분된다.
- 두 요청은 독립적으로 실행되며 각각 20초 한도를 둔다. 기존 응답이 지연되어도 이메일 접수 안내를 막지 않는다. 한 페이지에서 중복 클릭·재제출을 막고, 이메일 실패나 불확실성에는 입력을 보존하고 직접 이메일 문의를 안내한다.
- 양식에는 FormSubmit 전달 항목·목적·운영자 수신 주소·서비스의 30일 보관 안내와 필수 동의를 추가한다. 기존 개인정보처리방침의 문의 항목과 외부 전달 안내도 같은 사실로 맞춘다. 다른 프로그램과 기존 보유 기간은 유지한다.
- 이번 작업에서는 실제 문의 POST·시험 이메일·뉴스레터 등록·도메인 설정을 수행하지 않는다. 기존 FormSubmit 주소의 활성화와 수신 테스트는 `docs/renewal-v0-1.md`의 과거 운영 기록이며, 이번 변경으로 새 수신 확인을 대신하지 않는다.

전체 자동 테스트 66개와 `npm run build:review`가 통과했다. 실제 정적 빌드의 문의 HTML·개인정보 안내·전달 스크립트가 원본과 같음을 확인했다. 브라우저에서 직접 이메일 링크, 기존 입력 항목, 전달 동의와 활성화된 제출 버튼을 확인했으며 926px 화면에서 가로 넘침이 없었다. 실제 제출 없이 확인했으므로 받은편지함 도착은 검증하지 않았다.

### 도메인 주소의 무료 수신 전달 준비

사용자는 `contact@arunia.co.kr` → `hwajeongup@gmail.com` 무료 수신 전달부터 진행하기로 선택했으나, 가비아가 다른 관리 계정이라 접근이 어렵다고 밝혔다. 2026-10-08 공개 DNS 조회에서 네임서버는 `ns.gabia.co.kr`, `ns1.gabia.co.kr`, `ns.gabia.net`이며 MX·루트 TXT는 NOERROR/응답 없음, `_dmarc`는 NXDOMAIN이었다. 현재 연결된 도메인 메일 수신 서버는 확인되지 않는다. 도메인 메일 활성화는 홈페이지 코드 수정과 별도이며, 도메인 관리 권한 없이 완료했다고 표시하지 않는다.

무료 수신안은 ImprovMX 계정에 `arunia.co.kr`을 등록하고 `contact` 별칭의 전달 목적지를 `hwajeongup@gmail.com`으로 지정하는 것이다. 가입·로그인 후 실제 서비스 화면의 값과 기존 DNS를 다시 확인하고, 도메인 관리자에게 아래 세 레코드만 등록하도록 요청할 수 있다. 웹사이트 A/CNAME과 네임서버를 바꿀 필요는 없다. 현재 이 레코드나 전달 별칭을 실제 등록하지 않았다.

| 종류 | 호스트 | 값 | 우선순위 |
| --- | --- | --- | --- |
| MX | @ | mx1.improvmx.com | 10 |
| MX | @ | mx2.improvmx.com | 20 |
| TXT | @ | v=spf1 include:spf.improvmx.com ~all | — |

[ImprovMX 공식 DNS 안내](https://improvmx.com/guides/generic-dns-configuration/)와 [가격표](https://improvmx.com/pricing/)를 확인했다. 무료 플랜은 1개 도메인·25개 별칭·하루 500통 전달을 제공하며 발신 SMTP는 포함하지 않는다. 따라서 무료 수신 완료 후에도 `contact@arunia.co.kr`로 발신하려면 별도 서비스가 필요하다. 당장 도메인 관리자에게 접근할 수 없으면 홈페이지 양식과 공개 Gmail 직접 문의를 사용한다.

Gmail은 2027년 1월부터 타사 이메일의 Send as를 중단한다고 [공식 변경 안내](https://support.google.com/mail/answer/17101213)에서 설명한다. Google 호스팅 주소는 예외다. 장기적으로 Gmail 웹에서 도메인 주소로 발신하려면 Google Workspace 같은 별도 메일 계정이 필요하며, 기존 개인 Gmail로의 수신 전달도 별도로 설정해야 한다. 유료 가입·결제·새 인증정보·메일 발신 설정은 이번 무료 수신 선택에 포함하지 않는다.
