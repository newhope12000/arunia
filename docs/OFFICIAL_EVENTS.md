훈민정음은 기존 이름·연락처·숫자 나이 20~27·시도/시군구/동읍면·네 줄·동의·미리보기·최종 제출 구조를 보존한다. 특정 거주지 예시는 없다. 무작위 5자리 접수번호와 동일 제출 ID 재확인, 저장 확인 전에 성공으로 표시하지 않는 처리를 유지한다. 훈민정음 시트의 I열은 전체 거주지, J/K/L열은 지역 세 항목이며 AC열은 접수번호다. Telegram에는 이름·연락처·나이·전체 거주지·네 줄·접수번호가 이미 포함된다. 공개 화면의 나이 표기는 ‘나이’이며 기존 저장 스키마의 H열 ‘만 나이’ 이름과 숫자 age 필드는 데이터 호환성을 위해 유지한다.

도메인 이동에 필요한 서버 변경은 두 수집 API의 정확한 출처 허용 목록이다. `https://www.arunia.co.kr`, `https://arunia.co.kr`, 기존 `https://arunia-silk.vercel.app`과 수집 서버 자신의 출처를 허용하고 유사 도메인·임의 미리보기 도메인은 허용하지 않는다. 중앙 handler와 기존 수집 서버 원본을 함께 맞춘다. API·봇·시트 탭·Apps Script 배포 주소와 비밀값은 재사용한다.

CORE-UP의 기존 9월 30일 마감은 연장하지 않았다. 이번 작업은 도메인·경로와 기존 연동의 통합이며 자동 마감·수상자 선정·결과 자동 게시를 새로 구현하지 않는다. 기존 문의·리더십·그만둘만두의 다른 수신 흐름과 상담 시안 API는 별도 기능으로 유지한다.

## 싱크 기록

참여자가 홈페이지와 응모 사이트의 브랜드·주소가 달라 혼동하는 문제를 줄이기 위해 한 공식 도메인 안에서 안내→응모→접수 확인으로 연결한다. 설명을 읽고 싶은 이용자와 빠르게 응모하려는 이용자를 함께 지원하는 설계 가설이다. MBTI별 행동을 검증된 사실로 단정하지 않는다.

데이터 확인 후 정한 구현 범위는 공식 저장소 최신 main 기준의 행사 파일 추가, 기존 화면에서 공식 행사 진입 링크 추가, CORE-UP의 서로 다른 접수 링크 정리, 수집 API 출처 허용 수정이다. 상담 리뉴얼 시안과 기존 다른 운영 흐름을 전면 교체하지 않는다. 배포 전 빌드 및 경로·자산·폼·출처 검증, 배포 후 공식 페이지와 읽기 전용 접수 준비 상태를 확인한다.

## 훈민정음 거주지 수집 범위 축소 · 2026-10-02

추가 요청에 따라 새 응모는 시·도와 시·군·구까지만 받는다. 동·읍·면 입력칸, 전송 항목, 미리보기와 해당 수집 안내를 제거한다. 필요한 지역 정보만 받아 입력 부담을 줄이는 변경이며, MBTI별 반응을 검증된 사실로 단정하지 않는다. 숫자 나이는 ‘만’ 표기 없이 기존 참여 범위인 20~27세를 유지한다.

변경된 개인정보 수집 범위는 `arunia-hunmin-v2`로 기록한다. 중앙 수집기와 기존 Apps Script는 새 버전을 함께 허용하고, 기존 v1 제출·중복 재확인도 지원한다. 기존 시트 탭, 전체 거주지 I열, 시·도 J열, 시·군·구 K열, 과거 동 정보 L열과 접수번호 AC열은 보존한다. 새 응모의 L열은 비워 두고 전체 거주지와 알림에는 시·도/시·군·구만 표시한다. 이전 응모의 거주지와 제출 식별 정보는 수정하지 않는다. 내부 스키마 v1 및 기존 H열 이름은 데이터 호환성을 위해 유지하며 새 알림의 나이 라벨은 ‘나이’로 표시한다.

필요한 서버 변경을 먼저 적용한 뒤 공식 신청폼을 배포한다. 모의 검증은 동 없는 20세 제출, 27세 허용, 19·28·소수 나이 거부, 필수 지역 누락 거부, 기존 v1 재시도와 새 v2의 저장·알림 정보, 불확실한 접수의 동일 ID 재확인 및 5자리 접수번호를 포함한다. 실제 신청 행이나 Telegram 시험 알림은 만들지 않는다.

검증: 공식 사이트 전체 테스트 55개와 배포 빌드, 중앙 API 회귀 27개, 기존 API·시트·알림 모의 테스트 38개가 통과했다. 중앙 변경 커밋은 `5db925f`다. 기존 Apps Script 웹 앱은 2026년 10월 2일 21:27 KST에 v55에서 v56으로 업데이트했고 URL·실행 계정·접근 설정을 유지했다. 프로젝트 기록 비교에서 별도 Supabase 미배포 변경을 발견해 운영 v55 원본을 기준으로 훈민정음 변경만 버전에 담았으며, 해당 작업의 Head 원본은 배포 직후 정확히 복원·저장했다. 다른 운영 파일이나 시트의 기존 셀을 수정하지 않았다.

## 훈민정음 거주지 표시를 도시·시로 수정 · 2026-10-03

검증: 전체 테스트 55개와 `npm run build:review`가 통과했다. 실제 응모 행이나 시험 알림은 만들지 않는다.

## 훈민정음 뒤 거주지 항목을 시·구로 수정 · 2026-10-03

두 항목의 내부 이름, 기존 시트 탭과 열, 20~27세 나이 및 v2 접수 연동은 유지한다. 기존 미리보기·전송·재확인 테스트에서 시와 구를 함께 작성한 문자열이 그대로 전달되는지 확인한다. 실제 접수 행이나 시험 알림은 만들지 않는다.

검증: 신청폼·행사 경로 회귀 11개 및 배포 빌드가 통과했다. 수집기·시트·Telegram의 외부 전송 없는 모의 확인에서도 도시와 시·구 문자열이 그대로 유지된다.
